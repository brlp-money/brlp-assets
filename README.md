## Stellar

The authoritative `stellar.toml` is served from the asset's home domain:

```
https://brlp.money/.well-known/stellar.toml
```

The copy in this repository is for reference only. It is generated by `tsl-anchor` and should not be edited by hand. When the live file changes, replace this copy with the new one.

## Updating

When you add a network or change an address:

1. Update `contracts.json`.
2. If the network is EVM, add the token to `brlp.tokenlist.json` and bump `version` and `timestamp` (major when removing a token or changing an address, minor when adding a token, patch for other metadata changes).
3. Update the address table in this README.
